# Miku's Utawaku Stream

## 2025 Magic Mirai programming contest lyric app

“Miku’s Utawaku Stream” is a livestream-style web platform built with React and Tailwind CSS. Viewers can join a virtual Hatsune Miku performance, send chats and superchats, and even control the stream in real-time using simple hand gestures. Whether you click “GO” to grant camera access or opt out, onboarding guides you through gesture and chat tutorials, then you’re free to enjoy an immersive Vocaloid experience entirely in the browser.

## How to run the code

To set up and run the project locally, follow these steps:

1. Open the app folder:
   `cd app`
2. Install the necessary dependencies:
   `npm install`
3. Start the development server:
   `npm start`

The app will be available at http://localhost:3000/. If you see any initial runtime errors, simply close them and click “GO” again. For best results use desktop at 100% zoom, though tablets also work.

## How to play

Follow the onboarding prompts to learn chatting and gesture controls, then tap “GO” to start the stream. Send chat messages or superchats, and wave or make a fist in front of your camera to trigger fun effects!
